# USER_JOURNEY_AND_FLOW.md
> SEISMOLIVE 통합 사용자 여정 및 상태 플로우 설계서  
> 공통 원칙: **층수·호실·실내 구조 입력 배제** / **진앙과 사용자 위치 엄격 분리** / **내 위치·자유 모드 단일 엔진 공유**

---

## 0. 실험실 최초 진입 UX 설계 (2-트랙 공통 관문)

기존처럼 실험실 진입 직후 특정 대학 건물(212동 3층 301호)과 대피 동선이 무작정 재생되지 않는다.  
실험실 진입 시(지구본 사건 없이 직접 진입하는 경우) 사용자에게는 **단 두 가지 간결한 시작 방식**만 제시한다.

```
┌──────────────────────────────────────────────────────────┐
│  SEISMOLIVE 지역 대응 분석 시작                             │
│                                                          │
│  [ A. 내 위치 기준 시작 ]                                 │
│  브라우저 위치 권한으로 현 위치 주변 지형·도로·대피 후보와      │
│  인근 지진 이력/시나리오를 자동으로 분석합니다.                │
│                                                          │
│  [ B. 자유 모드 (지역 직접 지정) ]                          │
│  국내 지명/주소를 검색하거나 지도에서 위치를 선택해             │
│  실제 지진 기록 또는 교육용 지진 시나리오를 탐색합니다.          │
└──────────────────────────────────────────────────────────┘
```

- **권한 거부 시 무중단 전환**: A에서 Geolocation 거부/오류 발생 시 오류 화면에서 멈추지 않고 `"위치 확인 권한이 없어 자유 모드로 전환합니다. 분석할 지역명 또는 주소를 입력하세요."` 안내와 함께 즉시 B의 검색 입력창에 포커스를 둔다.
- **초기 화면에서 요구하지 않는 정보**: 주소 상세 동·호수, 건물 층수, 실내 평면/방 번호, 개인 이동약자 세부 등급은 초기 진입 UI에서 완전히 제거한다.

## 1. 시나리오 A — 기존 지구본에서 실제 지진을 선택해 지역 대응까지 이어지는 경우

**목표 경험**: `GLOBAL EARTH → EARTHQUAKE → LOCAL SPACE → HUMAN RESPONSE`의 가장 자연스러운 연결.

1. **[Stage 1: GLOBAL EARTH] 지진 발견**
   - 사용자가 메인 지구본(`EXPLORE`)에서 글로벌 USGS 지진 비콘(예: `2016 경주 ML 5.8`, `2017 포항 Mw 5.4`, 또는 USGS 실시간 4.5+ 국내·동아시아 지진) 또는 아카이브 카드를 클릭한다.
   - `#view-selected`(사건 도시에)가 열리며 공식 기관 출처(`USGS Official` / `KMA`), 규모, 깊이, 진앙 오차 범위, (존재 시) USGS ShakeMap MMI 등진도와 P·S파 주시 곡선을 확인한다.
2. **[Stage 2: EARTHQUAKE] 사건 강하 및 파동 시각화**
   - 사용자가 `현장 강하 및 3D 시각화 재생 시작`을 누르면 `FlightController`가 해당 진앙 좌표의 3D 지역 지형(Copernicus/ETOPO DEM) 위로 하강한다.
   - `WavefieldVisualOrchestrator`가 P파·S파·표면파 전파를 시각화하고 사운드필드와 시간 스크러버(`#transport-scrubber`)가 동기화된다.
3. **[Stage 2 → 3 전환] 연속 맥락 전달**
   - `#view-selected` 및 `#view-performance` 하단/우측에 배치된 **`[이 지진의 지역 대응 분석 →]`** 액션을 누른다.
   - 시스템은 현재 `NormalizedEarthquakeEvent`(사건 ID, 진앙 좌표, 규모, 깊이, ShakeMap/OAF 유무, 출처 등급)를 `ActiveHazardContext`에 담아 그대로 로컬 공간 분석 상태로 넘긴다. (사건 선택 초기화 금지)
4. **[Stage 3: LOCAL SPACE] 위치 선택 및 공간 로딩**
   - 시스템이 질문 없이 간결한 위치 확인을 띄우거나 기존 확보 위치를 활용한다:
     - 옵션 1: **`내 현재 위치 기준 분석`** (예: 서울에 있는 사용자가 포항 지진에 대한 내 위치 영향 확인)
     - 옵션 2: **`진앙 인근 지역 공간 보기`** (예: 포항 흥해/경주 구도심 실제 지형·건물·도로·개활지 로딩)
   - 선택한 `analysisAnchor` 주변 OSM 건물 외곽·보행로·수계/교량·개활 후보지 및 AWS Terrarium DEM을 수집한다(초기 1.8km → 희소 시 최대 4km+ 확장).
5. **[Stage 4: HUMAN RESPONSE] 교차 판단 및 시각화**
   - 진앙 인근(`IN_IMPACT_ZONE`) 선택 시:
     - 먼저 **"P파 도달 후 주 진동 구간(엄폐 안내) → 진동 종료 후 이동 판단"** 짧은 인트로 브리핑(선택/건너뛰기 가능) 후, 실제 보행망 기반 대피 후보 경로(수계 비교량 차단, OBB 무충돌)와 진앙 방위선을 3D 공간에 표시한다.
     - 지도 위 다른 건물/지점을 클릭하면 해당 위치 외곽 출구 기준으로 경로를 즉시 재탐색한다.
   - 원거리(`OUTSIDE_IMPACT_ZONE`, 예: 서울에서 경주 M5.8 조회) 선택 시: 시나리오 E로 분기하여 거짓 대피 경로를 그리지 않고 거리·영향 미미 사실과 특보 확인 안내만 표출한다.

## 2. 시나리오 B — 내 위치 기준으로 진입해 관련 지진을 자동 탐색하는 경우

1. **[진입] A. 내 위치 기준 선택**
   - 사용자가 지구본 우측 상단 또는 실험실 관문에서 `내 위치 기준`을 클릭한다.
   - `LocationProvider.detectBrowserLocation()`이 위도·경도·오차 반경(`±accuracyMeters`)을 확보한다 (`Origin: OBSERVED`).
2. **[LOCAL SPACE 구축] 내 주변 실제 공간 추출**
   - 확보된 사용자 좌표를 `analysisAnchor`로 설정하고 DEM과 OSM 공간 데이터(건물 외곽, 보행로, 공원·학교 운동장·집결지, 하천·교량)를 수집한다.
   - 사용자 위치와 주변 건물 중 하나가 일치할 필요는 없으며, 사용자 위치 핀과 주변 건물 외곽은 시각적으로 구분 표시된다.
3. **[EARTHQUAKE 자동 탐색] `AutoScenarioResolver` 실행**
   - 시스템이 별도 입력 없이 자동으로 지진 상황을 판정한다:
     - **(b-1) 실제 지진 탐지 시**: 최근 KMA/USGS 피드 중 현재 위치 영향권(또는 최근 30일 감진 가능 거리) 내 실제 지진이 있으면 이를 최우선으로 바인딩하고 `"실제 관측 사건 자동 연결 (출처·거리)"` 배지를 띄운다.
     - **(b-2) 현재 실제 지진 부재 시**: 해당 권역의 과거 역사·계기 지진 이력(있을 경우) 또는 사용자 위치 인근의 **교육용 가상 단층 시나리오(`EDUCATIONAL_SYNTHETIC`)** 를 자동 구성한다.
     - 헤더에 `"현재 위치 반경 내 최근 실제 지진이 없어 교육용 지역 단층 시나리오(M5.x, 참고 거리 x km)로 자동 구성했습니다"`라고 1줄로 이유를 설명하며, 필요 시 `"과거 인접 기록으로 보기"` 전환 토글 1개만 제공한다.
4. **[HUMAN RESPONSE] 내 위치 맞춤 대응 안내**
   - `"내가 어디서 출발해 어떤 후보지로 가야 하는지"`를 최단·무단차/대체 경로(보행 가능 시)와 단계별 행동 지침, 그리고 해당 목적지가 `CONDITIONAL`(공식 API 미확인)인지 `CONFIRMED`인지의 신뢰도 한계와 함께 제공한다.

## 3. 시나리오 C — 자유 모드에서 특정 지역을 선택하고 실제 지진을 활용하는 경우

1. **[진입] B. 자유 모드 선택 → 지역 지정**
   - 사용자가 `"경주 황남동"` 또는 `"속초 청초호"`, 주소 검색, 또는 지도 클릭으로 `analysisAnchor`를 지정한다.
2. **[실제 지진 자동 매칭]**
   - 사용자가 모드 전환 또는 기본 시나리오 제안에서 **`실제 지진 기록`**을 선택한다.
   - `AutoScenarioResolver`가 해당 지역과 물리적으로 연결되는 실제 관측 사건을 우선 매칭한다:
     - 경주 지역 → `2016.09.12 경주 M5.8 (KMA-2016-GYEONGJU)`
     - 포항 지역 → `2017.11.15 포항 M5.4 (KMA-2017-POHANG)`
     - 부안 지역 → `2024.06.12 부안 M4.8 (KMA-2024-BUAN)`
     - 기타 임의 지역 → KMA/USGS 통합 카탈로그 중 해당 지역에서 가장 유의미한 실제 계기 관측 사건 (또는 지구본에서 탐색한 최신 USGS 사건)
3. **[지진-공간-대응 연결]**
   - 실제 진앙(예: 내남면 단층 `35.760°N, 129.190°E`)과 사용자가 지정한 지역 중심(`35.8347°N, 129.2190°E`)의 실제 거리(`8.7 km`), 방위, ShakeMap/감진 정보(존재 시)가 계산된다.
   - `IN_IMPACT_ZONE` 판정이 나면 경주 구도심 실제 도로·하천/교량·개활 공간(`CONDITIONAL`)으로의 보행 대응 시뮬레이션이 시작된다.
   - 이 과정에서 **"2016년 실제 관측된 M5.8 지진을 기준으로, 현 시점 경주 지역 도로망과 개활 후보지 조건을 분석한 교육/대응 시뮬레이션"**임이 출처 라벨에 명확히 드러난다.

## 4. 시나리오 D — 자유 모드에서 교육용 가상 지진을 자동 구성하는 경우

1. **[진입 및 조건]**
   - 사용자가 자유 모드에서 임의의 국내 도시·동네(예: `서울 강남역`, `속초 교동`, `부산 해운대`)를 선택한다.
   - 해당 지역 반경 내 최근 주요 계기 지진이 없거나, 사용자가 `교육용 시나리오`를 선택한다.
2. **[수동 입력 없는 자동 구성]**
   - 사용자는 진앙 위도·경도·규모·깊이를 한 칸도 입력하지 않는다.
   - `AutoScenarioResolver`가 분석 지역의 지형(해안가/충적 하천/산간/고밀도 도심), 지역 지진 환경, 주변 공간 데이터 가용성을 고려해 합리적인 교육용 파라미터를 자동 생성한다:
     - 예(속초·동해안 연안): 동해안 해역/연안 단층 가정 `M5.4 / 깊이 12km / 해역 방위 ~10km` (`EDUCATIONAL_SYNTHETIC`) + 하천/해안 저지대 주의 플래그 활성화.
     - 예(서울 고밀도 도심): 내륙 천부 단층 가정 `M5.2 / 깊이 10km` (`EDUCATIONAL_SYNTHETIC`) + 고층 외벽 낙하물 이격 반경 중심 후보지 평가.
   - 생성된 이벤트에는 반드시 `scenarioType: EDUCATIONAL_SYNTHETIC`, `"시스템 자동 구성 교육용 시나리오 — 실제 발생 지진 아님"` 배지와 선정 이유 설명이 붙는다.
3. **[대응 시뮬레이션 실행]**
   - P파·S파 도달 가정 안내 → 진동 중 실내/외 낙하물 엄폐 지침 → 흔들림 종료 후 보행망 기반 최선 후보지 이동 및 도착 후 여진·재진입 금지 교육까지 일관된 3D 경험으로 이어진다.

## 5. 시나리오 E — 지진 영향이 미미하거나 데이터가 부족해 대피 시뮬레이션을 진행하지 않는 경우

SEISMOLIVE는 **모든 상황에서 억지로 파란 대피선을 긋지 않는 것**을 핵심 제품 신뢰도 기준으로 삼는다.

1. **유형 E-1: 진동 영향권 외 (`OUTSIDE_IMPACT_ZONE`) 또는 경미 감진 (`MARGINAL_FELT_ZONE`)**
   - 예: 사용자가 `내 위치 기준`(서울)을 유지한 채 `2016 경주 M5.8` 또는 `일본 구마모토 Mw 7.0` 사건의 지역 대응을 조회함.
   - **시스템 동작**:
     - `HazardProvider`가 진앙 거리(예: `276.5 km`)와 영향 반경을 계산해 `OUTSIDE_IMPACT_ZONE` 판정.
     - 보행 대피 경로 및 3D 보행 마커 비활성화 (`canNavigate = false`), 경로 스크러버 비활성.
     - 3D 공간에는 해당 지역의 현황과 진앙 방위선만 정갈하게 유지하고, 차분한 안내 카드에 **"현재 분석 위치는 해당 지진의 직접 영향권 밖(거리 약 276.5km)이므로 옥외 대피가 불필요합니다"**를 표시한다.
     - 후속 액션 제시: `[진앙 인근 지역 공간으로 이동해 보기]` 또는 `[현재 위치 기준 교육용 시나리오로 전환]`.
2. **유형 E-2: 역사 문헌 사료 참고 전용 (`HISTORICAL_REFERENCE_ONLY`)**
   - 예: 지구본에서 `1681 양양 역사지진`을 선택한 경우.
   - **시스템 동작**: 사료 추정 좌표·규모 미상(`null`) 불확실성을 그대로 보존하며, 현대 실시간 경보처럼 대피 경로를 강제하지 않고 **"역사 사료 기반 참고 시나리오 (현대 교육 시뮬레이션 전환 가능)"** 로 명확히 구분 안내한다.
3. **유형 E-3: 공간 데이터 부족 (`INSUFFICIENT`) 또는 도달 가능 대피 후보 없음 (`UNAVAILABLE`)**
   - 예: 설악산 산간, 해상, 또는 OSM 도로/건물/공터 데이터가 거의 없는 오지 좌표 지정.
   - **시스템 동작**:
     - 가짜 도로 격자·가짜 건물 블록·가짜 대피소를 단 하나도 생성하지 않는다.
     - 이전 지역의 3D 경로·마커·안내 카드를 완전히 소거(`clearVisuals`).
     - `데이터 부족 (INSUFFICIENT)` 및 `목적지 미확인 (UNKNOWN / UNAVAILABLE)` 배지와 함께 **"주변 보행 가능 도로망 및 확인된 개활 대피 후보 데이터가 부족하여 경로를 산출할 수 없습니다. 현장 안내 표지와 주변 개활지(낙하물 없는 넓은 공간)를 직접 확인하십시오"**라는 정직한 안전 지침만 표출한다.
