### 4.1 "원본 신뢰도 보존율 99.999749%" 표현의 과학적 결함 교정

- **오류 원인**: 해당 수치는 단순 계산식 $1.0 - (\text{MAE} / \text{Span}) = 1.0 - (0.00427 / 1704.0) = 0.99999749$에서 도출된 수치적 비율에 불과합니다.
- **교정**: 임의로 설정한 수직 스팬($1,704\text{m}$) 대비 양자화 반올림 오차의 비율을 마치 데이터 과학적 '신뢰도(Reliability)'인 것처럼 포장한 것으로, **해당 문구와 백분율 표기는 공식 보고서에서 전면 삭제**합니다.

### 4.2 양자화 정밀도(Quantization Precision)와 DEM 센서 정확도(Sensor Accuracy)의 엄격한 분리
UNORM16 인코딩에서 발생하는 수치 오차는 데이터 보관 및 GPU 텍스처 패킹 과정의 반올림 오차일 뿐, Copernicus DEM의 지형적 참값 정확도를 대변하지 않습니다:
- **UNORM16 양자화 저장 정밀도**:
  - 양자화 스텝 ($\Delta q$): $\frac{1704.0\text{ m}}{65535} = 0.026001\text{ m} \approx 2.60\text{ cm}$
  - 최대 이론 오차 ($\frac{\Delta q}{2}$): $13.00\text{ mm}$
  - 194.4만 개 픽셀 전수 실측 평균 절대 오차 (MAE): $4.27\text{ mm}$
  - 194.4만 개 픽셀 전수 실측 평균 제곱근 오차 (RMSE): $6.08\text{ mm}$
- **Copernicus DEM 센서 자체의 물리적 절대 정확도 (ESA 공인 스펙)**:
  - 절대 수직 정확도: $\text{LE90} < 4.0\text{ m}$ (평탄지 및 완경사지 기준 실측 약 $1.5 \sim 2.0\text{ m}$)
  - 상대 수직 정확도: $< 2.0\text{ m}$
  - 절대 수평 위치 정확도: $\text{CE90} < 6.0\text{ m}$
- **결론**: UNORM16의 $4.27\text{ mm}$ 오차는 원본 32-bit Float DEM 데이터를 16-bit 텍스처로 양자화할 때 원본 손실이 4밀리미터 수준으로 억제된다는 의미일 뿐이며, 지형 자체의 절대 고도가 4밀리미터 단위로 정확하다는 뜻이 아님을 분명히 규정합니다.

  2. **래스터 격자 평균화(Spatial Grid Averaging)**: 30m 픽셀 하나가 계곡의 좁은 자갈 바닥뿐 아니라 양쪽의 가파른 암벽 하단부를 동시에 포괄하므로, 면적 평균 고도가 계곡 최저점보다 높게 산출됩니다.
  3. **DSM 수관고(Canopy Height) 기여**: Copernicus DEM은 DTM(지표면)이 아닌 DSM(수관 표면)입니다. 오색 계곡의 울창한 침엽수/활엽수림 수관 높이($15 \sim 20\text{m}$)가 레이더 반사면으로 잡혀 바닥면보다 높게 측정됩니다.
- **판정 결론**: 지형적 협곡 특성과 DSM 특성에 기인한 자연스러운 물리적 현상이므로 **`CONDITIONALLY VERIFIED`**로 판정합니다.
