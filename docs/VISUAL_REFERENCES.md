## 1. REF-01: GENESIS CONCEPT BOARD ("Data, Nature, and Memory in Harmony")

![Genesis Concept Board](/Users/katsina/.gemini/antigravity/brain/17a06635-381a-4696-af01-da0acfb6b284/REF-01_GENESIS_CONCEPT_BOARD.jpg)

### 1.1 6개 패널의 구조와 본질적 의도
본 컨셉 시트는 SEISMOLIVE가 추구한 원초적 비전을 상·하단 6개의 영역으로 나누어 명시하고 있습니다.

1. **상단 1열: 3대 핵심 기둥 (The Three Pillars)**
   - **Concept A. Wave Symphony (지진의 파동이 만들어내는 빛의 교향곡)**:
     - 칠흑 같은 우주와 지구의 완만한 곡률 위에서 진앙으로부터 확산되는 빛의 파동.
     - 단순한 원형 링이 아니라, 대기권과 지각을 유기적으로 울리는 다층 공명 아치(Harmonic Arches)와 미세 필라멘트.
   - **Concept B. Impact Field (지진이 남긴 공간적 흔적과 영향의 확산)**:
     - 험준한 산악 사면을 사선으로 조망하는 구도.
     - 진앙 주변의 계곡과 단층을 따라 액체처럼 스며들고 응축되는 따뜻한 호박색(Amber) 에너지. 산맥의 능선 음영과 완벽히 결합.
   - **Concept C. Memory Flow (역사 속 기억이 흐르는 지진의 시간)**:
     - 밤의 한반도 지형 위로 나선형 궤적을 그리며 부유하는 시간의 빛줄기와 역사적 기록의 공간적 표출.

2. **하단 2열: 데이터와 과학의 예술적 번역 (Scientific Translation)**
   - **파동의 전파와 상호작용 (Wave Propagation)**:
     - 청록색(Cyan) 점 = **P-Wave**, 호박색(Amber) 점 = **S-Wave**.
     - 빠르고 미세하게 앞서 나가는 P파의 차가운 광선과, 뒤따르며 지형을 뒤흔드는 S파의 두텁고 따뜻한 에너지가 서로 얽히며 직조되는 빛의 그물망.
   - **지진의 영향 범위와 강도 (Spatial Impact)**:
     - 수정 메르칼리 진도 계급(MMI V ~ X).
     - 원색의 무지개 히트맵이 아니라, 지형의 굴곡을 타고 흐르는 고도화된 등고선 필드. 진앙 중심의 백색-황색 코어에서 외곽의 짙은 암적색 및 인디고 지형으로 자연스럽게 침강하는 감쇠.
   - **역사적 사료의 시각화 (Historical Memory)**:
     - 고요한 궁궐/전각의 실루엣 위로 피어오르는 기억의 빛과 기록들.

### 1.2 계승할 점 vs 보완·수정할 점 (Evolutionary Refinement)
- **계승할 점 (Adopt)**:
  - P파(Cyan `#38bdf8`)와 S파(Amber `#f59e0b`)의 명확한 물성 및 색채 분리.
  - 지형의 계곡과 능선을 따라 흐르는 MMI 진도 필드의 유기적 음영.
  - 지구 곡률과 로컬 산악 지형이 공존하는 장엄한 사선 원근 구도.
- **보완 및 진화 (Refine per Art Direction Rules)**:
  - 초기 컨셉의 'Concept C'에 묘사된 거대한 한자(`地震`, `朝鮮`)와 수직 비석(Stele)은 **Art Direction Rules에 따라 완전 배제**.
  - 대신 사료에서 추출한 **단 1~2개의 순수 한국어 단어(`흔들리다`, `울다`, `퇴조`)**가 대기 안개 층에 극히 낮은 불투명도(0.4~0.7)로 서늘하게 부유하도록 승화.

## 2. REF-02: VALLEY WAVE FILAMENTS (지형-파동 유기적 결합)

![Valley Wave Filaments](/Users/katsina/.gemini/antigravity/brain/17a06635-381a-4696-af01-da0acfb6b284/REF-02_VALLEY_WAVE_FILAMENTS.png)

### 2.1 시각적 특성과 미학적 성취
- **산맥과 파동의 위계**:
  - 검푸른 산봉우리들이 전경과 좌우를 엄숙하게 둘러싸고 있으며, 파동은 공중에 뜬 불필요한 구체가 아니라 **산맥 사이의 깊은 계곡 분지 바닥에 안개처럼 차오른 빛의 흐름**으로 존재합니다.
- **다층 필라멘트 리본 (Layered Ribbon Filaments)**:
  - 단 하나의 둔탁한 선이 아니라, 수십 겹의 가느다란 호박색/구리빛 광선 가닥들이 사인파와 물리적 간섭을 일으키며 겹쳐집니다.
  - 빛의 밀도가 높은 곳은 밝은 백황색으로 빛나고, 외곽으로 갈수록 반투명한 암적색으로 감쇠합니다.
- **대기 원근과 지평선 대비 (Horizon Contrast)**:
  - 원경의 산맥 너머 지평선에는 차가운 은청색(Cyan-Blue) 대기광이 얇게 깔려 있어, 전경의 따뜻한 호박색 파동과 극적인 **온/냉(Warm/Cool) 시각적 대비**를 완성합니다.

### 2.2 Three.js 기술적 번역 (Technical Shader Blueprint)
```glsl
// Concept: shader_wave_filaments (GLSL Vertex & Fragment)
// 계곡의 저지대(Elevation < h_threshold)를 따라 파동 에너지를 제한하고 다층 사인파 리본 생성
float valleyMask = smoothstep(500.0, 50.0, vWorldPosition.y); // 계곡 바닥 집중
float ribbonPhase = vGeodesicDist * 0.05 - uTime * 2.0;
float ribbon = sin(ribbonPhase) * cos(vWorldPosition.x * 0.02 + ribbonPhase * 0.5);
float intensity = pow(abs(ribbon), 16.0) * valleyMask; // 날카로운 리본 선예도
vec3 waveColor = mix(vec3(0.96, 0.62, 0.04), vec3(1.0, 0.95, 0.8), intensity);
```

## 3. REF-03: SUBLIME RIDGE CONTOUR (야간 모노리스의 정점)

![Sublime Ridge Contour](/Users/katsina/.gemini/antigravity/brain/17a06635-381a-4696-af01-da0acfb6b284/REF-03_SUBLIME_RIDGE_CONTOUR.png)

### 3.1 시각적 특성과 미학적 성취
- **85%+ 압도적인 암흑의 지배 (Dominance of Silence)**:
  - 화면의 대다수를 차지하는 묵직하고 서늘한 차콜 블랙의 암석 지형.
  - 불필요한 환경광을 완전히 걷어내어, 관람자에게 장엄한 고요와 지질학적 무게감을 전달합니다.
- **단 하나의 면도날 같은 파쇄선 (The Razor Rupture Seam)**:
  - 산맥의 가장 날카로운 능선 굴곡을 정확하게 따라 흐르는 가느다란 단 하나의 빛의 선.
  - 중심부는 선명한 온백색/호박색이며, 가장자리는 차가운 청백색으로 미세하게 번져나가는 프레넬성 발광.
- **빛을 스치는 능선 실루엣 (Grazing Rim Lighting)**:
  - 배경 봉우리의 칼날 같은 실루엣 뒤편에서 비추는 극히 미세한 백색 사광.
  - 지형의 입체감이 과장된 텍스처가 아니라, **날카로운 법선 벡터(Normal)와 사광의 교차점**에서만 드러납니다.

### 3.2 G1 "Stage Without Earthquake"의 절대적 기준
- REF-03은 SEISMOLIVE v4.0의 첫 번째 마일스톤인 **G1 단계가 증명해야 할 시각적 완성도의 살아있는 표본**입니다.
- 화려한 파동이나 애니메이션이 없더라도, **실제 DEM 지형의 실루엣, 40° 기준 사광, 그리고 깊은 어둠만으로 갤러리 전시가 가능한가?**라는 질문에 대한 명확한 해답입니다.
