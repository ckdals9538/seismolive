## 2. 렌더링 전 기술적 필수 확인 결과 (Technical Pre-Checks)

### 2.1 UNORM16 텍스처 하드웨어 정규화 및 Three.js 브리징
- **문제 발견**: Three.js r160의 `WebGLRenderer`는 기본적으로 `glFormat === gl.RED`일 때 `glType === gl.UNSIGNED_SHORT`에 대한 sized internalFormat 자동 분기(`R16`)를 내장하고 있지 않으며, `gl.R16` 심볼은 core WebGL2 컨텍스트에 직접 노출되지 않고 `EXT_texture_norm16` 확장에 존재합니다.
- **해결 및 브리징**:
  ```javascript
  const gl = renderer.getContext();
  const extNorm16 = gl.getExtension('EXT_texture_norm16');
  if (extNorm16) {
    gl.R16 = extNorm16.R16_EXT; // 33322 (0x822A)
  }
  demTexture.internalFormat = 'R16';
  ```
- **셰이더 샘플링 수치 일치 검증 (Deno Playwright 실측)**:
  - 대청봉 최고점 피크 ($38.11917^\circ\text{N}, 128.46528^\circ\text{E}$):
    - 원본 Uint16: `65520` (이론 고도: $1,703.61\text{m}$)
    - 셰이더 샘플링 정규화값: `0.99977112` $\to$ 복원 고도: **`1,703.61 m`** (수치 편차: $3.49 \times 10^{-9}$)
  - 대청봉 표석 지점: 원본 `65174` $\to$ 셰이더 복원: **`1,694.61 m`** (수치 편차: $2.44 \times 10^{-8}$)
  - 오색약수 협곡: 원본 `20278` $\to$ 셰이더 복원: **`527.26 m`** (수치 편차: $1.26 \times 10^{-8}$)
  - 양양 남대천 하구: 원본 `70` $\to$ 셰이더 복원: **`1.82 m`** (수치 편차: $2.49 \times 10^{-13}$)
  - 동해안 연안단구: 원본 `837` $\to$ 셰이더 복원: **`21.76 m`** (수치 편차: $2.36 \times 10^{-10}$)
  - 동해안 해수면 접점: 셰이더 복원: **`0.00 m`** (워터마스크)
- **판정**: **VERIFIED**. WebGL2 하드웨어 샘플러가 16-bit 정수를 $[0.0, 1.0]$ float으로 완전무결하게 정규화함을 실증함.

### 2.2 래스터 방향과 UV 정합성
- **래스터 메모리 구조**: Copernicus DEM 타일의 Row 0은 최북단(Latitude $38.30^\circ\text{N}$)입니다.
- **텍스처 바인딩 방향 실사**: `demTexture.flipY = false`일 때 WebGL 텍스처 좌표 $V=0.0$에 Row 0(북쪽)이 바인딩됨을 6개 기준점 전수 일치 테스트로 확인했습니다.
- **정합 보정**: 메쉬 생성 시 북쪽을 $+Y$ (또는 $-Z$, $V_{\text{mesh}}=1.0$), 남쪽을 $-Y$ (또는 $+Z$, $V_{\text{mesh}}=0.0$)로 배치하고, 셰이더에서 `demUv = vec2(uv.x, 1.0 - uv.y)`를 적용하여 지형의 동서남북 반전을 원천 차단했습니다.

### 2.3 수직 기준과 ECEF 변환 한계 명시
- **수직 기준**: 본 지형 씬의 고도는 Copernicus DEM의 **EGM2008 지오이드 기준 정표고(Orthometric Height, $H$)**입니다.
- **ECEF 타원체고 분리**: 표준 WGS84 ECEF 타원체고($h = H + N$)로의 변환 시 요구되는 국지 지오이드 기복($N \approx 20\sim 25\text{m}$)은 이번 국지 LookDev에서 임의의 부정확한 상수로 때우지 않았으며, **EGM2008 정표고를 곡률 반경 $R=63.71\text{ units}$ 지심 접평면 기하에 투영하는 과학적 근사**임을 명확히 규정합니다.

기존 G1-Step 0.1 감사에서 규명된 신뢰성 상태를 렌더링 성공을 이유로 상향하지 않고 엄격히 유지합니다:

## 6. 결론 및 다음 단계 제안 (Forward Pipeline)

### 결론
SEISMOLIVE v4.0의 첫 번째 실제 지형 렌더링(G1-Step 1)은 **"실제 지구의 지형 데이터만으로 숭고한 미디어아트 장면을 구축할 수 있다"**는 핵심 가설을 성공적으로 입증했습니다. 가짜 지형과 저급한 게임 VFX에 의존하지 않고도, 정밀한 지리공간 전처리와 엄격한 조각적 조명 설계만으로 미술관 전시에 걸맞은 압도적인 정지 화면 퀄리티를 달성하였습니다.

### 다음 단계 제안 (Phase G1-Step 2)
1. **타일 연속 확장 테스트 (Level 1 Multi-tile Stitching)**:
   - 인접 $1^\circ \times 1^\circ$ 타일(예: 강릉·오대산 권역)과의 심리스 지오메트리 스커트 접합 및 다중 텍스처 스트리밍 검증.
2. **동해 해저 수심(GEBCO Bathymetry)과의 실제 해안선 인터페이스 연결**:
   - $h = 0.0\text{ m}$ 해안선 접점에서 동해 깊은 심연 해구로 이어지는 해저 지형과의 무봉(Seamless) 블렌딩 LookDev 착수.
