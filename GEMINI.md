# SEISMOLIVE v4.0 — Project Governance & Rules

This project enforces strict artistic and geospatial integrity rules for AI pair programming.

All agent operations must strictly adhere to the project art direction rules defined in:
[.agents/rules/art_direction.md](file:///.agents/rules/art_direction.md)

### Core Mandates:
1. **Artistic Identity**: SEISMOLIVE is a sublime audiovisual media art work, NOT a game, NOT a dashboard, NOT an educational simulator.
2. **Strict Ban on Game VFX**: NEVER generate transparent glowing spherical domes, vertical laser cylinders, Hanja steles, rainbow heatmaps, or HUD metric cards.
3. **Continuous World**: The globe, local terrain, horizon, and sea exist in one unified 3D physical coordinate space.
4. **Historical Typography (Living Memory)**: Pure Korean archival words only (e.g. `흔들리다`, `울다`, `퇴조`). Low opacity, atmospheric integration, no Hanja, no 3D stone steles.
5. **Geospatial & Scientific Integrity**: Real DEM/Bathymetry data only. Unknown values must remain `uncertain` or `null`. Never invent fake GMPE formulas.
6. **Still Frame Perfection**: A single frozen frame must stand on its own as gallery-worthy art through lighting, atmosphere, and terrain silhouette alone.
